### **How Each Tier Operates**

#### **Tier 1: `shutil.which` (System & Command-Line Executables)**

* **Role:** Instant zero-cost check.
* **How it works:** Checks the System `PATH` for built-in system tools (like `notepad`, `calc`, `cmd`) or developer CLI tools (like `git`, `python`).
* **Action:** If found, launches the executable immediately using `subprocess`.

#### **Tier 2: `AppOpener` (Primary Heavy-Lifting & Fuzzy Matcher)**

* **Role:** Handles 90% of standard desktop applications and handles spoken typos automatically.
* **How it works:** Tries to match the app name against its built-in index.
* **Action:** Executes `AppOpener.open(name, match_closest=True)`. If `AppOpener` raises an exception or fails to find the app, execution safely drops to Tier 3.

#### **Tier 3: PowerShell `Get-StartApps` (UWP & Windows Store Apps)**

* **Role:** Catches modern Windows AppX / UWP packages that standard executable scanners miss (such as Xbox, Windows Settings, Microsoft To-Do, or custom Store installs).
* **How it works:** Runs a quick background PowerShell query `Get-StartApps` using Python's `subprocess` module.
* **Action:** Matches the user's requested name against the returned list of App IDs (e.g., `Microsoft.WindowsCalculator_8wekyb3d8bbwe!App`) and launches it using the Windows `explorer.exe shell:AppsFolder\...` protocol.

#### **Tier 4: Start Menu `.lnk` Shortcut Scanner with `pywin32` (Ultimate Fallback)**

* **Role:** The safety net for obscure or newly installed desktop software that skipped standard registration.
* **How it works:** Crawls both Start Menu directories (`C:\ProgramData\...` and `C:\Users\<User>\AppData\...`). Uses `pywin32` (`win32com.client`) to resolve any `.lnk` file whose name matches the target into its underlying target `.exe` path on disk.
* **Action:** Launches the target `.exe` directly.

---

### **How to Structure This in `src/tools/app_control.py**`

Instead of scattering these scripts across multiple places, keep them neatly packaged inside `src/tools/app_control.py`:

1. **Helper Functions (Internal):**
* Write internal helper functions for the PowerShell scan (`_try_powershell`) and Start Menu `.lnk` scan (`_try_start_menu`).


2. **Main Public Function (`open_application`):**
* Put all four steps inside a single `try...except` sequence.
* Step 1 runs `shutil.which`. If successful, stop.
* Step 2 runs `AppOpener`. If successful, stop.
* Step 3 runs `_try_powershell`. If successful, stop.
* Step 4 runs `_try_start_menu`. If successful, stop.
* If all four steps fail, return a clean error string back to `main.py` so the voice engine can report that the app was not found.



---

### **Why This Multi-Tier Setup Keeps Code Clean**

* **Separation of Concerns:** `main.py` and `brain.py` only ever call one function (`open_application`). They don't care *which* tier succeeds.
* **High Reliability:** By combining fuzzy matching (`AppOpener`), UWP store app detection (`PowerShell`), and physical shortcut checks (`.lnk`), your agent achieves practically 100% application detection on Windows.
